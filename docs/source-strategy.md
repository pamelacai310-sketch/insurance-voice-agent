# 来源策略

## 时间窗口

当前初始化窗口：2025-12-05 至 2026-06-05。

生产运行时窗口：从任务运行日向前回推 6 个月，包含起止日期，并记录运行时区。

## 来源类型

| 类型 | 示例 | 优先采集方式 | 风险 |
| --- | --- | --- | --- |
| 搜索结果 | Google/Bing/站内搜索结果 | 搜索 API 或合规搜索连接器 | 搜索结果非评论，需要二次抽取 |
| 论坛/社区 | Reddit、豆瓣小组、贴吧、行业论坛 | API 或 HTML crawler | 登录、反爬、删除帖 |
| 问答平台 | Quora、知乎类问答 | API/HTML/browser fallback | 长答案和评论需区分 |
| 视频评论 | YouTube、TikTok、B站等 | 官方 API、Actor、browser fallback | 评论折叠和分页复杂 |
| 新闻评论 | 门户新闻、财经媒体评论区 | HTML/browser fallback | 有些站点评论不可公开访问 |
| 应用商店评论 | App Store、Google Play、保险公司 App 评论 | 官方/第三方 review API | 评论与保险产品需关联 |
| 投诉平台 | 公开投诉网站、消费者反馈平台 | HTML crawler | 高 PII 风险，需严格脱敏 |

## 覆盖指标

- 每周新增来源数
- 每个平台有效评论数
- 每个保险品类评论数
- 近半年命中率
- 去重后保留率
- 低置信记录比例
- 需要人工复核的来源比例

## 接入优先级

1. 有官方 API 或稳定导出接口的来源。
2. 公开 HTML 且 robots/ToS 允许的来源。
3. 有成熟第三方 Actor/API 的复杂平台。
4. Browser agent fallback。
5. 暂缓：需要登录、强隐私、强反爬、明确禁止自动采集的来源。
