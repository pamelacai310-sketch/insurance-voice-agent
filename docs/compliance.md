# 合规边界

本项目只面向公开可访问的信息采集和统计分析，不采集私信、登录后私域内容、付费墙内容，且不绕过访问控制。

## 基本原则

- 尊重 robots.txt、平台服务条款和速率限制。
- 默认只保存脱敏文本；原始文本如因审计需要短期保存，应加密并设置保留期。
- 不采集身份证号、手机号、邮箱、详细地址、保单号等个人敏感信息；发现后应自动脱敏。
- 不对单个自然人画像，不输出可识别个人的排名、标签或结论。
- 不把采集到的用户评论数据提交到公开 Git 仓库。
- 对投诉平台、医疗险理赔等高敏场景，必须开启人工抽样复核。

## 禁止行为

- 绕过登录、验证码、付费墙或访问控制。
- 使用采集结果骚扰用户或做定向营销。
- 存储未脱敏的个人身份信息。
- 在不保留来源证据的情况下生成“全网结论”。
- 把模型推断当作事实，例如把“疑似误导销售”写成“确认误导销售”。

## 审计记录

每次采集任务应记录：

- 任务 ID、运行时间和运行人/服务账号。
- 来源 URL、来源类型、允许/拒绝原因。
- 抓取速率、错误率和重试次数。
- 使用的抽取模型、分类模型和 prompt 版本。
- PII 脱敏版本和抽样复核结果。
